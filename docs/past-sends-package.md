## How to read this package

- **Accepted** means Props Mailer submitted the message and Amazon SES accepted it. It does not guarantee inbox placement.
- **Dead** means a queue row ended in a terminal error.
- **Canceled** means a prepared recipient row was deliberately stopped and was not sent.
- Dates come from the queue's send date where available. Some older parent email records have no `sent_at` value even though their queue rows completed.
- A **direct/test audience** means no production mailing-list ID was attached to the successful queue row.
- One-recipient and four-recipient draft checks are separated into the test appendix.
